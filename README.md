# Veil

EraX Small ONNX로 사진을 브라우저 안에서만 분석하고 검열하는 로컬 우선 웹 편집기입니다. 선택한 사진과 추론 결과는 서버로 업로드되지 않습니다.

## 기능

- EraX Small ONNX 로컬 추론 및 편집 가능한 자동 검열 사각형
- 사각형 이동, 모서리 크기 조절, 선택 삭제
- 흰색 검열 브러시와 검열 마스크 전용 지우개
- 최대 60단계 실행 취소/다시 실행
- 화면 배율과 무관한 원본 해상도 PNG 저장
- JPG, PNG, WebP 파일 선택 및 드래그 앤 드롭

## 실행

```powershell
pnpm install
pnpm dev
```

GitHub Pages용 프로덕션 빌드는 `npm run build`로 생성하며 `/censor/` base를 사용합니다. Tauri 패키지는 `npm run build:desktop`으로 상대 경로 자산을 생성합니다. EraX 모델은 `public/models/erax`에 포함되어 있어 실행 중 외부 모델 서버에 접속하지 않습니다.

## 데스크톱 앱과 HQ-SAM 2

`npm run tauri build`로 Windows용 Veil 앱을 빌드할 수 있습니다. 데스크톱 앱에서는 선택 기능인 HQ-SAM 2 공식 체크포인트를 앱 내부에서 내려받습니다. 다운로드 중에는 `.part` 파일을 사용하고 완료된 뒤에만 모델 파일로 교체하므로, 중단된 파일을 설치 완료로 취급하지 않습니다. 웹 버전에는 이 대용량 모델 다운로드 UI가 표시되지 않습니다.

HQ-SAM 2 추론 엔진은 Python과 PyTorch를 포함한 독립 실행형 사이드카입니다. 개발 환경에서는 `npm run sidecar:build`로 생성하고, `npm run tauri:bundle`로 사이드카가 포함된 NSIS 설치 프로그램을 빌드합니다. 모델이 설치된 데스크톱 앱에서는 **AI 검열 실행** 한 번으로 EraX 탐지와 HQ-SAM 2 윤곽 정밀화를 순서대로 수행합니다. 정밀화에 실패한 영역은 누락시키지 않고 EraX 사각형으로 유지하며, 반환된 RLE 윤곽 마스크는 기존 브러시·지우개·검열 효과와 함께 렌더링합니다.

생성된 윤곽 마스크는 캔버스나 편집 도구의 목록에서 개별 선택할 수 있습니다. 선택한 윤곽은 삭제·표시·숨김·재정밀화할 수 있고, 원본 해상도 기준으로 확대·축소하거나 페더를 조절할 수 있습니다. 이 변경은 실행 취소 기록과 원본 해상도 PNG 마스크에 동일하게 반영됩니다.

HQ-SAM 2 윤곽 점수가 90% 미만이면 해당 영역을 여백 포함 ROI로 잘라 확대 추론합니다. 박스 중심과 장축에는 양성점을, 박스 바깥에는 음성점을 주며 중심에 연결된 마스크 성분만 남기고 3px 안전 여백을 적용합니다. 최종 점수가 90% 미만이거나 마스크가 프롬프트 박스 밖으로 과도하게 퍼지면 해당 윤곽을 버리고 안전하게 EraX 사각형을 유지합니다.

데스크톱 앱의 **다중 이미지 배치**에서는 JPG·PNG·WebP 파일을 여러 장 대기열에 추가한 뒤 한 장씩 EraX → HQ-SAM 2 분석을 실행합니다. 분석 결과는 자동 저장되지 않으며, 각 항목을 편집기에 열어 검토하고 브러시·지우개 등으로 수정할 수 있습니다. 편집이 끝나면 현재 이미지, 선택 이미지 또는 모든 이미지를 원하는 시점에 PNG/JPEG로 저장합니다. 대기열의 이미지 삭제는 원본 파일을 삭제하지 않습니다. 파일 끌어놓기와 클립보드 이미지 붙여넣기도 지원합니다.

HQ-SAM 2 추론 엔진은 첫 정밀화 때 모델을 한 번 로드한 뒤 앱이 실행되는 동안 상주하며, 이후 단일 이미지와 배치 이미지가 같은 모델 인스턴스를 재사용합니다. 따라서 첫 이미지에는 모델 초기화 시간이 포함되지만 다음 이미지부터는 반복 로딩 시간이 제거됩니다.

AI 검열을 다시 실행하면 이전 자동 탐지 결과는 새 결과로 교체되지만 사용자가 그린 브러시·지우개 기록은 유지됩니다. HQ-SAM 2가 윤곽을 만들지 못한 탐지 사각형은 안전을 위해 검열 상태로 유지하되, 편집기에서 주황색 **확인 필요** 항목으로 분리됩니다. 사용자는 해당 사각형을 유지 승인하거나 삭제할 수 있으며, 미확인 사각형이 남은 이미지를 저장할 때는 경고가 표시됩니다.

## 단축키

- `V`: 선택/이동
- `B`: 흰색 브러시
- `E`: 마스크 지우개
- `Delete`: 선택한 AI 사각형 삭제
- `Ctrl+Z`: 실행 취소
- `Ctrl+Shift+Z`: 다시 실행
