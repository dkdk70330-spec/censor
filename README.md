# Veil

EraX Small ONNX로 사진을 브라우저 안에서만 분석하고 검열하는 로컬 우선 웹 편집기입니다. 선택한 사진과 추론 결과는 서버로 업로드되지 않습니다.

## 기능

- EraX Small ONNX 로컬 추론 및 편집 가능한 자동 검열 사각형
- 사각형 이동, 모서리 크기 조절, 선택 삭제
- 흰색 검열 브러시와 검열 마스크 전용 지우개
- 최대 60단계 실행 취소/다시 실행
- 화면 배율과 무관한 원본 해상도 PNG 저장
- JPG, PNG, WebP 파일 선택 및 드래그 앤 드롭

## 실행

```powershell
pnpm install
pnpm dev
```

프로덕션 빌드는 `npm run build`로 생성합니다. EraX 모델은 `public/models/erax`에 포함되어 있어 실행 중 외부 모델 서버에 접속하지 않습니다.

## 데스크톱 앱과 HQ-SAM 2

`npm run tauri build`로 Windows용 Veil 앱을 빌드할 수 있습니다. 데스크톱 앱에서는 선택 기능인 HQ-SAM 2 공식 체크포인트를 앱 내부에서 내려받습니다. 다운로드 중에는 `.part` 파일을 사용하고 완료된 뒤에만 모델 파일로 교체하므로, 중단된 파일을 설치 완료로 취급하지 않습니다. 웹 버전에는 이 대용량 모델 다운로드 UI가 표시되지 않습니다.

HQ-SAM 2 추론 엔진은 Python과 PyTorch를 포함한 독립 실행형 사이드카입니다. 개발 환경에서는 `npm run sidecar:build`로 생성하고, `npm run tauri:bundle`로 사이드카가 포함된 NSIS 설치 프로그램을 빌드합니다. 모델이 설치된 데스크톱 앱에서는 **AI 검열 실행** 한 번으로 EraX 탐지와 HQ-SAM 2 윤곽 정밀화를 순서대로 수행합니다. 정밀화에 실패한 영역은 누락시키지 않고 EraX 사각형으로 유지하며, 반환된 RLE 윤곽 마스크는 기존 브러시·지우개·검열 효과와 함께 렌더링합니다.

## 단축키

- `V`: 선택/이동
- `B`: 흰색 브러시
- `E`: 마스크 지우개
- `Delete`: 선택한 AI 사각형 삭제
- `Ctrl+Z`: 실행 취소
- `Ctrl+Shift+Z`: 다시 실행
